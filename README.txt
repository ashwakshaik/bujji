REGISTRATION FORM

How to run:
1. Extract registration_form.zip.
2. Open the extracted folder.
3. Double-click index.html, or open it with your web browser.

Files:
- index.html: Registration form structure
- style.css: Form design and responsive layout
- script.js: Basic password confirmation and submit interaction

Note:
This is a front-end demo. It does not save user details or connect to a database.
